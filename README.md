# Assignment 5: Greedy Solution Designer

## Files
- `greedy_optimizer.py`: completed greedy implementations and tests
- `delivery_generator.py`: generates the three benchmark scenarios
- `greedy_analysis.docx`: written greedy-property and complexity analysis

## Run
```bash
python delivery_generator.py
python greedy_optimizer.py
```

The optimizer runs the unit tests automatically. If the generated `scenarios/` JSON files are present, it also runs benchmarks. Benchmark timings depend on your computer and the randomly generated input, so report the actual output from your own run.
